## Sensor Calibration

### How Calibration Is Applied

Sensor extrinsic calibration data is measured for each robot during production.<br />
If the file or a sensor entry is absent, the affected sensors use URDF defaults.

- **File**: `~/ANTBOT/calibration.yaml`
- **Reference**: Sensor position and orientation relative to `base_link`
- **Application**: `antbot_bringup` replaces the URDF default coordinates with calibration values for sensor TFs

| Field | Meaning | Unit |
| :--- | :--- | :--- |
| `tx`, `ty`, `tz` | X, Y, Z position | Meters (`m`) |
| `rx`, `ry`, `rz` | Roll, Pitch, Yaw | Radians (`rad`) |

### Example File

| Key | Sensor | TF Frame |
| :--- | :--- | :--- |
| `camera_front_extrinsic` | Front mono camera | `camera_mono_front_link` |
| `camera_left_extrinsic` | Left mono camera | `camera_mono_left_link` |
| `camera_right_extrinsic` | Right mono camera | `camera_mono_right_link` |
| `lidar_2d_back_extrinsic` | Rear 2D LiDAR | `lidar_2d_back_link` |
| `lidar_2d_front_extrinsic` | Front 2D LiDAR | `lidar_2d_front_link` |
